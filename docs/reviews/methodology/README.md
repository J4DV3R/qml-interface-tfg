# Artefactos de revisión metodológica

Este directorio está reservado para informes que el coordinador asigne
expresamente al agente `methodology`. El metodólogo es de solo lectura en el
resto del repositorio.

- No guardes aquí JSON de resultados experimentales de origen; esos archivos
  permanecen en `results/`.
- No uses este directorio para reescribir documentación de otros agentes.
- Cada informe debe indicar alcance, fuentes consultadas, hallazgos por
  severidad, evidencia y veredicto.
