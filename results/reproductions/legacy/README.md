# Reproducciones de la etapa histórica

Este directorio está reservado para **repeticiones** de los experimentos de la
primera etapa (QCNN + PyTorch + Adam). No sustituye ni sobrescribe los
resultados originales, que están congelados en
[`results/initial-hybrid-adam/`](../initial-hybrid-adam/).

Usar este directorio si se vuelve a ejecutar alguno de los comandos históricos
para comparar, depurar o verificar la reproducibilidad. Los resultados del
nuevo entrenamiento no híbrido deben ir a
[`results/quantum-training/`](../quantum-training/).

Convención propuesta:

```text
results/reproductions/legacy/<fecha>-<experimento>.json
```
